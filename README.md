# Wordly · 考研单词记忆

一个安静、专注的考研英语背词工具。纯前端，双击 `index.html` 即可离线使用，不需要 Python、不需要本地服务器。

## 使用

1. 下载或克隆本仓库。
2. 双击 `index.html`（或 `start.bat`）。

学习记录保存在浏览器本地（`localStorage`），换设备前请用「偏好与数据」里的导出功能备份。

## 功能

- 20 章、1964 个考研词汇，每章每个词只过一遍
- 一行两张卡：左边单词、右边释义，释义默认高斯模糊，按 `↓` 才揭开，不翻面、不多动画
- 整章单词纵向铺开，滚动或按键切换当前词；已掌握的词灰化排在章末
- 键盘操作：`↓` 显示释义，`↑` 上一个词，`←` 还不认识，`→` 记住了（标记后自动前进）
- 生词本（收藏与「不熟」合并为一份名单）、拼写练习、全库搜索
- 深浅色主题、可收起侧栏、学习进度自动保存
- 学习数据导出 / 导入

## 文件说明

| 文件 | 说明 |
|---|---|
| `index.html` | 页面结构 |
| `styles.css` | 样式与动画 |
| `app.js` | 交互与本地存储 |
| `data.js` | 内嵌词库（20 章 / 1964 词），由 `build-data.js` 从 `data/` 生成 |
| `build-data.js` | 词库构建脚本，Node.js 运行 |

## 词库更新

原始词库位于 `data/chapter-*.json`，修改后运行：

```bash
node build-data.js
```

会重新生成 `data.js`。

## 历史

本项目早期为 Python + PyWebView 桌面版，现已改为纯前端实现，`app.py` 仅作历史保留。
